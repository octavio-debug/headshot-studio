# Headshot Studio

Turn any photo into an on-brand Infloww headshot. The photo is processed on your device and never uploaded.

Created by Gülnaz. Shown in the Infinni intranet under Tools → Headshot Studio.

Background removal uses [RobustVideoMatting](https://github.com/PeterL1n/RobustVideoMatting) (GPL-3.0) running in the browser with TensorFlow.js.
